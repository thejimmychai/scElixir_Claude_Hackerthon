# `scMagnify` Lung Development Multiome Vignette Gallery (`vignette_output/scmagnify/`)

Complete **20-figure (`40` dual `300-DPI .png` + vector `.svg` files) + primary `.csv` evidence suite** extending the 13-package `vignette_output/` catalog (`scanpy`, `harmonypy`, `bbknn`, `quadbio_css`, `umap_learn`, `scipy_statsmodels`, `celloracle`, `scenicplus`, `pyscenic`, `regvelo`, `dynamo`, `networkx`, `pertformer`) with **Package #14: `scmagnify`** (`v0.1.1-scelixir-repro`, Chen et al., *bioRxiv* `10.64898/2026.02.03.703669v1`).

Every vignette reproduces an official output format from the `scMagnify` preprint and tutorial notebooks (`100`–`500`) on our harmonized **Human (`5 PCW -> 56.8 yr`, `10,256` epithelial cells + `11,486` adult `snATAC` nuclei)** and **Mouse (`E12.5 -> P3 / 7 wk`)** developmental lung multiomes.
