## What this round added

- **Stage E live query fixed.** The previous code passed a `{up, down}` dict where the
  engine expects a gene list, so the query searched for the literal words "up" and
  "down", and the reverse direction was never run. A regression test pins both
  directions and the gene lists.
- **Capability report** — `GET /compute/status` (`?probe=1` also checks the external
  hosts). Each engine reports its missing packages, files and weights. Every
  not-computed stage returns a `requires` list naming exactly what is absent.
- **Durable artifacts** — `data/results/`. A result is served only for an identical
  identity (stage, organ, layer, source, target, species, route, engine parameters).
  Lung reference data is never copied into the results folder.
- **Route-aware Stage C** — the CellOracle route no longer returns the SCENIC+ table.
- **Run-and-poll in the UI** — a "Request computation" action on not-computed stages.
  Offline, it is disabled and explains why.
- **Offline snapshot** — `frontend/standalone.html` embeds the backend's own responses
  for every UI path (generated by `scripts/build_standalone.py`). Checked in the
  browser: 8 of 9 sampled requests are byte-identical to live output. The one
  difference is a non-default transition, which falls back to the seed adapter and is
  reported as not computed, with different wording.
- **Port fallback** — if the default port is taken, the server binds the next free
  port and prints the URL. On macOS the Claude desktop app's own service can hold
  port 8765, which would have stopped the app from starting there.
- **Validation** — invalid species, route, engine JSON, signatures and bodies return
  HTTP 400 with a reason.

## Still open, in suggested order

1. Install `requests pandas scipy` in a virtualenv and run one real LINCS/Tahoe
   signature query. Record the output as the first Stage E artifact.
2. Put one organ's integrated sub-atlas in `data/external/` and wire the CellOracle
   route (Stage C, then D). The `requires` list will show when it is found.
3. Persist job records (a small JSON store) so long runs survive a restart.
4. Stage F: a Modal dispatcher behind the existing button, keeping the explicit-action gate.
5. Liver: produce a bundle from a real hepatocyte atlas and run the same spine.
6. Expose engine parameters (alpha, score_quantile, candidate pool) in the UI. The API
   already accepts them and keys results on them.
